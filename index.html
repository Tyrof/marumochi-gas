📖 実物のGoogle Apps Script（GAS）の使い方

このドリルで練習したコードは、実物のGASでもそのまま使えます。まずは実物の画面を開いて、1回動かしてみましょう。

1. GASのエディタを開く
・Googleスプレッドシートを開く（新規でも練習用でもOK）
・上のメニュー「拡張機能」→「Apps Script」をクリック
・新しいタブでコードを書く画面（エディタ）が開く。これがGASのプラットフォームで、コードはGoogleのサーバー上で動く
2. エディタ画面の見方
・中央：コードを書く場所（最初から書いてある myFunction は消してOK）
・上のプルダウン：実行する関数を選ぶところ
・上のボタン類：保存（フロッピーのマーク）と実行（▶のマーク）
・実行すると、下に「実行ログ」が出る
3. まず試すコード
function helloGas() { const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); sheet.getRange('A1').setValue('こんにちは、GAS！'); Logger.log('A1に書き込みました'); }
4. 保存して実行する
・保存ボタンを押す（または Ctrl+S、Macは ⌘+S）
・プルダウンで helloGas が選ばれていることを確認して「実行」を押す
5. 初回だけ出る「権限の承認」
・最初の実行だけ、権限の確認画面が出る（自分で作ったものでも必ず出るので、怖がらなくて大丈夫）
・「権限を確認」→ 自分のGoogleアカウントを選ぶ
・「このアプリは確認されていません」と出たら「詳細」→「（プロジェクト名）に移動」→「許可」の順に進む
・許可すると実行がそのまま続く
6. 結果を確認する
・スプレッドシートのタブに戻ると、A1に「こんにちは、GAS！」と入っている
・エディタの下の実行ログに「A1に書き込みました」と出ていれば成功。ドリルの「実行ログ」と同じ役割
7. このドリルとのつながり
・ドリルで練習した getValue / setValue / getValues などは、実物でもそのまま使える命令
・ドリルで書いたコードを実物のエディタに貼って試すのが、上達への近道
8. つまずきやすいところ
・実行する関数を間違えた：プルダウンで関数名を確認する
・シートが見つからないエラー：getSheetByName('売上') の名前が、実際のシート名と一致しているか確認する
・変更が反映されない：保存し忘れが多い。実行前に Ctrl+S
